## Configuration
| Name | Default Value | Description
|:-----:|:-----:|:-----:
| `Continuous Updates` | `true` | Toggles whether the elevator will continually update its velocity vector every frame.
| `MaxForce` | `inf` | The maximum force the elevator will act on objects at, measured in studs per second per second
| `Speed` | `5` | The speed the elevator will move objects at, measured in studs per second
| `Vector` | `"UpVector"` | Determines which normal vector of the `BasePart` the force is acted on.
